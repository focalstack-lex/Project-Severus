# Portfolio NFC

Physical-to-digital business card platform linking customized hardware NFC cards (metal, wood, matte PVC) directly to dynamic, mobile-optimized profile landing pages (`/p/[username]`).

## Architecture & Stack
- **Framework**: Next.js 15 (App Router) + React 19 + TypeScript (Strict Mode)
- **Styling**: Tailwind CSS v4 + Design Tokens (Obsidian & Executive Glass themes)
- **Database & ORM**: SQLite + Prisma ORM
- **Contact Export**: Dynamic `.vcf` vCard download endpoint
- **Design Directive**: Strict Zero-Emoji policy with minimalist Lucide SVG vector icons

## Core Links & Pillars
- Connected to [[The Glorious Evolution]] ecosystem and [[Second Brain]].
- Built following [[Zero Hallucination Directive]], defensive engineering, and [[UI Audit and Design System]] guidelines.
