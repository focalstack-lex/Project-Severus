# Slash Command Secure

Custom slash command `/secure` executable in any chat session/IDE to run the 10-step full security audit against the Security-First Deployment Gate. Related: [[Security-First Deployment Gate]], [[Agent Skills]], [[The Glorious Evolution]]. #skills #security #command #slashcommand #glorious-evolution

```markdown
---
name: secure
description: Run full Security-First Deployment Gate check on the active workspace (secrets, npm audit, Auth/AuthZ, CORS, CSP, input validation, DB sanitization, rate limits). Triggers on /secure or when user asks for a security audit.
---
```
