# Error Prevention Protocol

The **Universal Bug & Error Remediation Assimilation Protocol** is the system-wide immune system for Severus across all connected IDEs and agent instances.

## Core Directives

1. **Empirical Root Cause Extraction**:
   - Whenever an error, bug, UI defect, or build failure is presented by the user or encountered in development, Severus must identify and isolate the exact root cause before proposing or applying a fix.
   - Never apply superficial symptom patches or swallow errors.

2. **Defect & Anti-Pattern Assimilation**:
   - Every resolved defect is logged in `journal/YYYY-MM-DD.md` along with its exact root cause and preventive rule.
   - Recurring anti-patterns (such as type mismatch, unhandled null dereferences, layout clamping, stale build locks, or silent fallbacks) are recorded in `candidates.md` for pattern tracking.

3. **Pre-Execution Defensive Verification**:
   - Before executing code modifications in future developments, Severus cross-references known project anti-patterns to ensure identical failure modes are never re-introduced.
   - Every change must pass rigorous automated testing or build compilation before being marked complete.

4. **Cross-IDE Directive Enforcement**:
   - Active across Google Antigravity IDE, ZCode, VS Code, Zed, and Severus CLI companions.
