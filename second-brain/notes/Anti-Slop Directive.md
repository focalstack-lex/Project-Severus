# Anti-Slop Directive

Universal `/antislop` command for auditing and preventing AI slop across any project in any IDE (Antigravity, ZCode, Cursor, VS Code, Zed, Cline).

## Six Core Audit Lenses
1. **Visual & Typography Slop**: Uniform corner radius ("rounded everything"), brand color oversaturation (violating the 80/15/5 rule), inconsistent product image canvas/scaling, floating dev/framework artifacts (e.g. Next.js 'N' badges), default dark themes, decorative blur orbs.
2. **Structural & UX Slop**: Component showcase syndrome, badge/pill proliferation, repeated trust declarations vs evidence-based trust (replacing "100% Authentic" repetition with exact branch stock, 30-point diagnostics, 1-year warranty), generic 4-card trust bars, weak commercial utility in hero sections, card hierarchy deficiencies, unused gap spacing, admin routes in public nav.
3. **AI-Writing & Retail Copy Markers**: Banned phrase density, robotic marketing rhythms ("Reserve Online, Pay In-Store Upon Claiming"), lack of local geographic grounding, interchangeability test.
4. **Code Slop**: Comment noise, dead exports, single-use abstractions, unjustified dependencies, unstyled library output, magic numbers.
5. **AI Search Visibility**: Google AI Mode probe, citable entity presence, JSON-LD structured data, robots directives.
6. **Ad Clutter & Shallow Depth**: Ad ratio, autoplay media, fake proof, placeholder testimonial walls.

## Fix and Prevention Doctrine
- **Shape Contrast**: Hero 24px, Promos 20px, Cards 12-16px, Buttons pill, Search 10-12px, Images 8-12px, Small tags 6-8px, content sections unboxed.
- **Color Scarcity (80/15/5)**: 80% neutral/white, 15% dark navy/slate, 5% brand accent.
- **Evidence-Based Trust**: Specific facts over repeated slogans.
- **Badge Discipline**: Prune badges that do not drive immediate user purchasing decisions.
- **Product Photography System**: Strict 1:1 canvas, 70-75% object scale, unified background, centered alignment.
