# tools/

Home for self-made CLI tools (Ascension Guide §3). When a task needs a utility that doesn't
exist yet, build it here, document it, and add a line to the journal.

Conventions:
- One tool per file or folder, named after what it does
- Prefer standard-library-only Python so tools run on any machine with Python installed
- Every tool starts with a docstring: purpose, usage, and an example invocation
