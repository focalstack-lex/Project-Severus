# Severus.ai — UI/UX Audit & Visual Refinement Plan

## Part 1 — Audit findings (every item verified at file:line)

**A. AI-slop artifacts (your explicit red lines)**
1. **Emoji as icons** throughout the shell: TopHeader `⌂ 🕸️ 📚 ✦ 🔍 ⚡` (TopHeader.tsx:78-146), SidebarNav `⌂ 🔍 📚 ⚡ ✦ ✎ ⚙` (SidebarNav.tsx:84-204), Home dashboard `📝 🕸️ ✦` (App.tsx:551-575), toasts `👏 🗣️` (App.tsx:172, 191-234), glyph pseudo-icons `✕ ⓘ ⟲ ▾ ▸` (GraphView.tsx:367-377, SidebarNav.tsx:61,113).
2. **Glowing dots**: `.status-dot` box-shadow glows ×3 (styles.css:3149-3157, 3514-3526), 2D selected-node blur halo (GraphView.tsx:221-226).
3. **Gradient glass capsule** + inset white glare + heavy shadow (styles.css:3005-3010) — the generic-glassmorphism signature.
4. **Lying legend**: HUD claims blue=note / yellow=hub / green=selected (GraphView.tsx:384-398) but 2D actually colors nodes by first tag (App.tsx:398-406).

**B. Broken / unfinished UI**
5. Entire **Home dashboard is unstyled** — `.home-dashboard/.dash-card/...` have zero CSS (App.tsx:541-581).
6. Entire **Node Inspector mode is unstyled** — `.node-card/.stat-box/...` (ContextInspector.tsx:139-215).
7. Footer items unstyled beyond the base bar (`.human-footer/.footer-item/.val` — App.tsx:639-665).
8. **Fake navigation**: sidebar "Work & Context"/"Journal"/"Settings" set `activeSection` but only open modals — center still shows the graph with a wrong breadcrumb (SidebarNav.tsx:149-207); the "Tags & Index" sub-tab does nothing (App.tsx:541-603); unused `"collections"` type (TopHeader.tsx:6); the `breadcrumb` prop is computed (App.tsx:409-426) but never rendered.

**C. Design-system debt**
9. **Token lie**: `--font-main` requests "Geist"/"Instrument Sans" but index.html:11 loads only Inter + JetBrains Mono.
10. **Four uncoordinated near-blacks**: #040404 (styles.css:8), #050505 (index.html:12), #0b0e14 (tauri.conf.json window bg), #090b0e (GraphView.tsx:75), plus ~8 more ad-hoc surface greys (0c0c0c, 121212, 0a0a0a...).
11. `fade()` blends toward the wrong background `[0x0b,0x0e,0x14]` (colors.ts:6) vs actual canvas #040404.
12. 188 hex + 169 `rgba()` literals; **no spacing/radius/shadow/z-index tokens**; 20 font sizes including 8px/9.5px; 23 backdrop-filters; ad-hoc z-ladder 10→100.
13. Global `button:hover` inverts **every** button to solid white (styles.css:114-118).
14. No `:focus-visible` anywhere; `--text-dim` #505050 on black ≈ 2.6:1 contrast (WCAG fail).
15. 2D graph is a **static ring layout** regardless of topology (GraphView.tsx:157-166) — size encodes PageRank but structure is invisible.

**D. Craft/UX details**
16. Wrong shortcut hints: header "Grounding" says Ctrl+J (that's Journal — App.tsx:363), switcher says Ctrl+N (real: Ctrl+Alt+N — App.tsx:386), footer/header show ⌘K on Windows.
17. Invalid class names `class="graph-container 2d"` (GraphView.tsx:353-355) — unmatchable in CSS; `.canvas-graph-container/.canvas-map` rules orphaned (styles.css:3756-3767).
18. Dead code: ActivityRail.tsx (166 ln) + RightWorkbench.tsx (112 ln) unimported; dead CSS (.topbar:198, .activity-rail:325-428, .right-workbench:738-824); duplicate h4 rule (styles.css:1521/1532); empty section banner (2979-2983).
19. No React error boundary; no initial loading state (blank canvas until IPC returns); pervasive silent `catch {}`.
20. Prior critique (.impeccable/critique/2026-09-12, 30/40) already flagged the rainbow tag palette — the 6 saturated hues persist (colors.ts:4).

*Note: plan mode blocked launching the app, so this audit is static; a live screenshot baseline is Step 0 of implementation.*

## Part 2 — Direction (confirmed with you)
Refined floating capsule header; monochrome chrome with color only as information (muted tag hues in graph/tags context only). Impeccable "Operate" mode: scanability and precision over expression. Identity stays "monochrome obsidian workstation" per README.md.

## Part 3 — Implementation steps

**Step 0 — Visual baseline.** `npm run dev` (vite :1420), open in the automation browser with a runtime-injected `window.__TAURI_INTERNALS__` mock seeded from the real 6 vault notes (JS port of the small PageRank in graph.rs) — no repo pollution. Screenshot all views/states for before/after comparison.

**Step 1 — Foundation (tokens, fonts, surfaces).**
- Extend `:root` in styles.css: spacing (4/8/12/16/24/32), radius (4/6/8/12/999), shadow (rest/raised/overlay), z-ladder (nav 20/drawer 25/popover 30/modal 50/toast 60). Unify surfaces to one family: canvas #050505, surface #0a0a0a, raised #101010, overlay #141414 — applied to index.html, tauri.conf.json `backgroundColor`, 3D bg + 2D clear color, popover, capsule.
- Load **Geist** (400-700) + JetBrains Mono from Google Fonts; `--font-main: "Geist"`. Type scale: 11px floor (kill 8/9.5px), steps 11/12/13/15/20/28.
- colors.ts: `BACKGROUND` → `[0x05,0x05,0x05]`; PALETTE v2 = muted, harmonized versions of the 6 hues.
- Interaction states: per-variant hovers (replace global white-invert), `:focus-visible` ring, lift `--text-dim` to ≥4.5:1, semantic success/warn/error. Remove all glow/pulse.
- Read `.agents/skills/impeccable/reference/craft-floor.md` before the first UI edit (skill requirement).

**Step 2 — Icon system.** New `components/Icon.tsx`: hand-rolled inline SVG set (~26 icons: home, graph, notes, search, spark, layers, plus, pen, settings, chevrons, close, external, info, reset, git-branch, mic, mic-off, clap, voice, copy, save, eye, edit, check, alert). 24-grid at 16px, stroke 1.5, currentColor, aria-hidden. Replace every emoji/glyph across TopHeader, SidebarNav, App, GraphView, modals.

**Step 3 — Shell.** TopHeader: solid #101010 capsule, 1px hairline border, restrained shadow token (no gradient/glare); SVG icons; platform-aware kbd hints (Ctrl on Windows); fix Grounding → Ctrl+Shift+G; flat status dot; toggle pills neutral on/off (red only for errors); delete dead `breadcrumb` prop. SidebarNav: SVG icons, group labels, active state with 2px left indicator, git footer = branch icon + text (dirty = amber text, no glowing dot).

**Step 4 — Center stage.** 2D canvas: deterministic hand-rolled force layout (repulsion + springs, ~120 iterations, ring-seeded) replacing the ring; selected node = white fill + crisp offset ring (no blur halo); truthful legend ("size = PageRank · brightness = freshness · color = primary tag" with real swatches). 3D: bg → token, styled `.node-label` chip. TagBar: obsidian chips with a flat 8×3px color tick — no rainbow borders, no glow dots. Toolbar/badge as quiet solid chips.

**Step 5 — Inspector & editor.** Write the missing Node Inspector CSS (stat grid, tag chips, excerpt, actions) in the token system; MarkdownPreview type scale (h1-h4, code, blockquote, wikilink/tag chips); Copilot: dedupe h4 rule, refine session bar and message styling.

**Step 6 — Home dashboard.** Design the unstyled Home into a real second-brain briefing: hero with greeting/date + vault stats (notes/links/tags from existing state), 3 action cards with SVG icons, "Hub notes" (top PageRank) and "Recent notes" lists.

**Step 7 — Honest navigation.** "Tags & Index" becomes a real center view (tag overview + note index table with importance/freshness, click → note). Work/Journal/Settings sidebar items become honest actions (no fake section/breadcrumb change). Remove `"collections"` type.

**Step 8 — Modals & feedback.** Unified modal chrome (overlay, surface, radius, shadow tokens, input focus rings); quiet toasts (no emoji); initial "Indexing vault…" loading state; React error boundary around GraphView/Copilot with quiet retry; correct all shortcut hints.

**Step 9 — Cleanup.** Delete orphaned ActivityRail.tsx, RightWorkbench.tsx, dead CSS blocks, duplicate rule, empty banner; rename `2d/3d` classes → `mode-2d/mode-3d` with CSS.
